# MoodiQuest API Tests (Agent-driven)

Это тестовый репозиторий для экспериментов с агентами (Codex).

Цель проекта — с нуля сгенерировать полноценный API тестовый фреймворк для MoodiQuest,
не написав самостоятельно ни одной строки кода вручную.

Проект создаётся полностью через задачи, описанные в `tasks/`,
а правила работы агента заданы в `AGENTS.md`.

---

## 🎯 Задача проекта

- Поднять API test framework на Java 21 + Gradle
- Использовать JUnit 5 + REST Assured + AssertJ + Allure
- Реализовать 8 API тестов для MoodiQuest
- Проверить, насколько корректно агент может:
    - понять OpenAPI контракт
    - создать структуру проекта
    - сгенерировать DTO
    - написать тесты
    - настроить отчётность


---

## ▶ Запуск тестов

Требования:
- Java 21

Запуск:

```
./gradlew test
```

## Как работает репозиторий

1. Правила для агента находятся в AGENTS.md
2. Конкретная задача описана в tasks/0001-bootstrap-framework.md
3. Агент читает эти файлы и генерирует весь код
4. Этот репозиторий создан как эксперимент: проверить, можно ли полностью делегировать создание тестового фреймворка ИИ-агенту.
5. Автор кода — агент. Человек только формулирует требования.
